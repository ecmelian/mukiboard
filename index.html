Tablero compartido en la nube

Con esto todo el equipo trabaja sobre el mismo tablero. Necesitas una base de datos gratuita de Firebase (console.firebase.google.com → crear proyecto → Realtime Database → crear en modo de prueba → copia la URL que termina en firebaseio.com o firebasedatabase.app). Luego comparte el "link del equipo" y todos quedan conectados.

⚠ La base en modo de prueba es pública para quien tenga el link: compártelo solo con tu equipo. En Firebase → Realtime Database → Reglas, pon {"rules":{".read":true,".write":true}} para que no caduque a los 30 días.
